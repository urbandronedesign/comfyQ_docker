Thunder Compute backup

For when RunPod has no free card. An API token from console.thundercompute.com → Settings → API Tokens. It can spend your credits, so it stays on this machine. Thunder's machines are in North America.

ComfyQ passwords

Invent these. A Pod is reachable by anyone who has its URL, so it will not serve without an admin password. The student password is optional: leave it empty and anyone with the link can book jobs.

Network volume

Where the models live between Pods. The GPU is rented in the same data centre.

The fallback for when the volume's data centre has no free GPU. RunPod puts the Pod in any data centre with the GPU free. It downloads its models at its first boot onto its own disk (Qwen Image 2.1 is about 16 GB, 2–3 minutes), and keeps students' results there too. That disk survives Stop and Start, but Terminate deletes everything on it: use Download results on the Pod before terminating. Gated models (FLUX.2, some LTX) need the HuggingFace token under Credentials.

Billed per GB every month, whether or not a Pod runs. A light bundle needs 20–40 GB of models; the whole library about 1.3 TB. Pick a data centre that has the GPUs you want (the GPU list below shows stock once the volume exists).

When are cards free?

RunPod keeps no history of its stock, so a GitHub job notes every 15 minutes which cards are free in each data centre. A reading says what RunPod listed at that moment; a card listed as free can still be taken a second later.
