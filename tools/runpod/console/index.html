    Create a Pod RunPod
    
  
    
    
    
      
    Network volume
    
      
    Where the models live between Pods. The GPU is rented in the same data centre.
    
      
    
        
        
        
      
    
      
    
        The fallback for when the volume's data centre has no free GPU. RunPod puts the Pod in any data centre with the GPU free. It downloads its models at its first boot onto its own disk and keeps students' results there too.
        That disk survives Stop and Start, but Terminate deletes everything on it: use Download results on the Pod before terminating.
      
    
      
    
        
    
          
          
          
        
    
        
    Billed per GB every month, whether or not a Pod runs. Pick a data centre that has the GPUs you want.

    Book machines RunPod, for a workshop
    
  
    
    
    From the start time, the console asks RunPod every minute for the machines still missing: only cards with at least the GPU size you set, at or under your price cap, cheapest first. A refused try costs nothing. Each machine found is kept: it starts serving the workflows below (downloading their models itself, a few minutes) and you are told. It runs while this app runs, window closed or not. Community Cloud has no network volume: each machine downloads its models to its own disk.

    Create an instance Thunder Compute
    
  
    
    
    OpenSSH is not installed on this PC, and the setup of a Thunder instance runs over ssh: the instance would be created (and bill) but never start ComfyQ. Install it first: Windows Settings → System → Optional features → OpenSSH Client.
    
    
    Machines in North America. The instance's own disk holds the models and the students' results, and deleting the instance deletes them: use Download results first. Billing runs from Create until Delete.

    Settings keys and passwords
    
  
    
    
    
      
    RunPod
    
      
    An API key with read and write access: RunPod → Settings → API Keys. It can spend your credits, so it stays on this machine.
    
      
      
    
    
    
    
    
      
    Thunder Compute
    
      
    An API token from console.thundercompute.com → Settings → API Tokens. It can spend your credits, so it stays on this machine.
    
      
      
    
      
    
    
    
    
    
      
    Vast.ai
    
      
    An API key from cloud.vast.ai → Account → Keys. It can spend your credit, so it stays on this machine.
    
      
      
    
    
    
    
    
      
    ComfyQ passwords
    
      
    A machine is reachable by anyone who has its URL, so it will not serve without an admin password. The student password is optional.
    
      
      
    
    
    
    
      
    HuggingFace optional
    
      
    Only for gated models (FLUX.2, LTX). A Read token, and accept each gated model's licence on its page.
